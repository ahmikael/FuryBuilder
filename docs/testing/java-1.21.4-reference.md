# Java 1.21.4 DataVersion reference

## Selection and evidence

The initial target remains **Minecraft Java Edition 1.21.4**, with
**DataVersion 4189**. This value was checked on 2026-11-17 by reading every
allocated chunk in an externally published region file:

- Source: [PrismarineJS/prismarine-provider-anvil, PR #107][pr].
- File: [`test/fixtures/1.21.4/r.0.0.mca`][file], pinned to commit
  `43231fc3f1f8194d2efc3498d060a28b47c05961`.
- Git blob SHA-1: `3e98a8710dbe5285814cee322b6f46085183f2de`.
- SHA-256: `9e73cba4d7ebb3662e96d167e55ca38cc949194bd208aadf26f1ab67bcefcb22`.
- File size: **1,880,064 bytes**.
- Observed root NBT field: **341 allocated chunks**, all
  `DataVersion: TAG_Int(4189)`.

The contributor states that the region was generated by the official 1.21.4
server using seed 12345. FuryBuilder did not run that server or independently
verify this account; the source is an open, unmerged pull request. The 341
allocated chunks include proto-chunks; they should not be confused with the
44 full chunks reported in the pull request.

The source package declares the MIT license for its code, but redistribution
rights for every piece of generated world content have not been established.
The region is therefore **not committed or shipped** by FuryBuilder. The
independently derived integer and hashes are retained for reproducibility.
The [Minecraft Wiki Data version table][versions] also lists 1.21.4 as 4189.

## Reproduce

Obtain the pinned region file locally through the link above, subject to the
source's terms, then inspect it without modifying it:

```powershell
Get-FileHash -Algorithm SHA256 <path-to-r.0.0.mca>
python scripts/inspect_reference_region.py <path-to-r.0.0.mca> --expect-version 4189
python -m unittest discover -s scripts -p "test_inspect_reference_region.py" -v
```

The inspection utility uses Python's standard library. It checks Anvil sector
locations and lengths, bounds decompression, and traverses NBT tags to read the
**root** `DataVersion`; missing, malformed, duplicate, or mismatched values
cause failure. The unit tests use synthetic data only.

Recorded output:

```json
{"chunks": 341, "dataVersionCounts": {"4189": 341}}
```

## Limits of this evidence

This establishes the chosen version identifier against an external region
fixture. It is **not** an interoperability or write-compatibility test: it does
not test Java structure files, verify block-state conversion, run Minecraft,
or demonstrate successful exports. Those checks remain separate roadmap tasks.
No Mojang executable, texture, or game asset is included.
