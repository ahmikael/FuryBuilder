# Minecraft Java 1.21.4 structure fixtures

These are original, deliberately small test arrangements created for
FuryBuilder and saved by the **official Minecraft Java 1.21.4 server**, not
generated by the FuryBuilder serializer or copied from a third-party map.
The arrangement is made available under the repository's [MIT license](../../../LICENSE);
this does not license or include Minecraft binaries, textures, or other assets.
The user authorized creating test data for this project. See
[`docs/formats.md`](../../../docs/formats.md)
for capture details and limitations.

| `plain.nbt` | `35a3f89de502cd9a6f1cc1b7496d4aebbfc336625389ef50dc5d22932849616b` | 1×2×1: stone bricks, east-facing oak stairs |
| `chest_boundary.nbt` | `ad4066be63af09d269c8b5c6297548b8c948daaaed2e74df238ea35267f8b7ad` | 2×2×2: stone bricks, stairs, air, empty chest with block-entity data; crosses world X=15/16 |

Both files are GZIP-compressed Java structure NBT with `DataVersion` 4189.
Their integrity and semantic contents are checked by:

```powershell
cargo test -p furybuilder-world-io --test game_fixtures
```

These reference **inputs** do not establish that FuryBuilder's exported
structures load correctly in Minecraft; that requires a separate integration
test.
